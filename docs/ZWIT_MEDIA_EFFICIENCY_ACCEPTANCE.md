# Critères d'acceptation qualité

La fonctionnalité n'est acceptable que si :

- aucune photo inférieure à 900 Ko et 2560 px n'est réencodée ;
- aucune vidéo n'est transformée ;
- le plein écran mobile et desktop reste net ;
- un échec d'optimisation conserve le fichier original ;
- les règles de modération et de confidentialité restent inchangées ;
- le gain de stockage est mesurable sur les nouveaux uploads ;
- le retour arrière ne nécessite aucune migration de données.
